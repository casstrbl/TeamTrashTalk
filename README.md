# Waste Monitoring System

## Overview

The Trash Talk Waste Monitoring System is a Java application designed to monitor waste levels across a university campus.

The system uses sensors to collect information about the fill levels of waste bins. Each waste station can contain three waste categories:

* Landfill
* Compost
* Recycling

The collected sensor data can be used to determine when bins are approaching or have reached their capacity and generate alerts so that waste can be collected when needed.

## Project Goals

The primary goals of this project are to:

* Monitor waste levels across a university campus.
* Track landfill, compost, and recycling bins.
* Collect and store sensor readings.
* Identify bins that need to be emptied.
* Generate alerts based on configurable fill-level thresholds.
* Organize waste data by bin and campus location.
* Provide a foundation for future integration with a database, sensors, and a user interface.

### Package Descriptions

#### `model`

Contains the classes that represent the main data and objects in the system.

Examples include:

* `Bin` — Represents an individual waste bin.
* `TriBin` — Represents a waste station containing landfill, compost, and recycling bins.
* `Sensor` — Represents a sensor associated with a bin.
* `SensorReading` — Represents a measurement received from a sensor.
* `Alert` — Represents a notification generated by the system.

#### `service`

Contains the application's main business logic.

Services can be responsible for tasks such as:

* Processing sensor readings.
* Determining whether a bin is full.
* Updating bin status.
* Generating alerts.
* Managing waste-monitoring operations.

#### `repository`

Contains classes responsible for storing and retrieving data.

This package can eventually be connected to a database to persist sensor readings, bin information, alerts, and campus locations.

#### `config`

Contains configuration-related classes, such as database connection settings.

#### `Application.java`

Contains the `main` method used to start the application.

## System Concept

A typical waste station contains three bins:

```text
                 Tri-Bin Station
                       │
          ┌────────────┼────────────┐
          │            │            │
      Landfill      Compost      Recycling
          │            │            │
       Sensor        Sensor        Sensor
          │            │            │
          └────────────┼────────────┘
                       │
                 Sensor Readings
                       │
                    Services
                       │
                    Database
                       │
                     Alerts
```

Each bin can have its own sensor so that the system can independently monitor the fill level of landfill, compost, and recycling.

## Example Workflow

1. A sensor measures the fill level of a bin.
2. The sensor produces a reading.
3. The application receives the reading.
4. The reading is associated with the appropriate bin.
5. The system determines the current status of the bin.
6. The reading is stored for future reference.
7. If the bin reaches a configured threshold, an alert can be generated.
8. Waste collection staff can use the information to determine which bins require attention.

## Getting Started

### Requirements

* Java Development Kit (JDK)
* Eclipse IDE
* Git (optional)

### Running the Project

1. Open Eclipse.
2. Import or create the `TrashTalk` Java project.
3. Make sure the project uses the appropriate JDK.
4. Locate `Application.java`.
5. Right-click `Application.java`.
6. Select **Run As → Java Application**.
